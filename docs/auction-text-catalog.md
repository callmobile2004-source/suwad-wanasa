# كتالوج المزاد النصّي — سَـوَاد وناسة

الحالة: **36 قطعة نصّية أولية، 3 قطع في كل فئة. الصور اختيارية ولا تدخل في شروط إنشاء الغرفة أو بدء الجولة.**

## قواعد الكتالوج

- جميع الأسعار والقيم بعملة لعب افتراضية اسمها WCOIN، ولا تمثل أسعار بيع أو تقييماً مالياً حقيقياً.
- قطع السيارات والساعات والألعاب والعقارات والطائرات والسفن والبطاقات والمعدات وصناديق المفاجآت **خيالية وأصلية داخل اللعبة**.
- قطع الآثار والتحف نسخ افتراضية مستوحاة من التاريخ، وليست آثاراً أصلية أو قطعاً قابلة للبيع أو التملك.
- فئة الحيوانات النادرة تثقيفية للحفاظ على البيئة فقط، وليست تجارة حيوانات.
- الصور غير موجودة في الدفعة الأولى. لا تعتمد بداية الجولة أو اختيار القطعة على وجود ملف وسائط.
- بيانات اللاعبين والمزايدات والأرصدة والغرف تبقى ضمن محرك المزاد الموثّق، والكتالوج لا يسمح للعميل بتعديل الأسعار أو الجوائز.
