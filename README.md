# سَـوَاد وناسة | Suwad Wanasa

منصة ألعاب تخمين عربية بطابع عراقي: **لَمّة، ضحك، وخَبْصة!**

## الموجود حالياً
- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.
- لعبة تخمين شخصية بجولات محلية تدريبية.
- لعبة تخمين رقم من 1 إلى 100.
- 17 فئة تخمين، منها الحيوانات والدول والمصارعين ولاعبو الكرة وشخصيات الألعاب والأنمي والأبطال الخارقون والمعالم والمهن.
- إعدادات أولية لنموذج إنشاء الغرف والانضمام إليها.
- ملفات PWA أولية لتجربة التثبيت والتخزين المؤقت.

## مهم قبل اللعب الجماعي
**الغرف ليست متصلة بين الأجهزة بعد.** إنشاء الغرفة والانضمام إليها حالياً واجهات تجريبية، والأجوبة لا تتم مزامنتها مع لاعبين آخرين. يلزم ربط خدمة خلفية لحظية لإضافة الغرف الحقيقية، حالة اللاعبين، الأسئلة والأجوبة المشتركة، والنقاط. لا تضع مفاتيح سرية أو كلمات مرور في ملفات الواجهة.

## التشغيل محلياً
افتح `index.html` عبر خادم ملفات محلي. لتجربة ميزات PWA، يجب استخدام HTTPS أو localhost.

## النشر
يمكن نشر الملفات الثابتة باستخدام GitHub Pages. راجع إعدادات المستودع في **Settings → Pages**، واختر **GitHub Actions** كمصدر للنشر إذا لم يكن مفعّلاً.
