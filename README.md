# سَـوَاد وناسة | Suwad Wanasa

منصة ألعاب اجتماعية عربية بطابع عراقي: **لَمّة، ضحك، وخَبْصة!**

## البنية الحالية

- واجهة عربية RTL وPWA قابلة للتثبيت.
- تخزين محلي وService Worker لملفات الواجهة والألعاب المحلية.
- Supabase Auth وPostgres وRLS للحسابات والغرف والتقدم والتواصل الاجتماعي.
- Edge Functions للمحرك الشبكي وأوراس والصوت: `room-engine` و`wanasa-ai` و`wanasa-tts`.
- توليد صوت أوراس والتعليم عبر Gemini TTS؛ يتطلب اتصالاً بالإنترنت، ولا يوجد حالياً محرك نطق محلي يعمل دون اتصال.

## الألعاب

### الألعاب المحلية

- خمّن منو آني، تخمين الرقم، برا السالفة، ممنوع إي ولا، ومنو الأكثر.
- عوالم محلية مستقلة: شفرة اللمة، مرسم اللمة، إعلان من كوكب ثاني، استوديو الدوبلاج، قلب الحكاية، مصنع الاختراعات، وبدون كلام.
- أوضاع اللمة المحلية تعني التناوب على الجهاز نفسه، ولا تعني وجود طور شبكي أو مزامنة بين الأجهزة.

### ألعاب الغرف الشبكية

توجد مسارات غرف لـحيّة ودرج، دومينوا، الطاولي، UNO، تحدّي الأسئلة، الشطرنج، والدولاب. بعض المحركات خادمية وتتحقق من الحركات، لكن وجود المحرك أو نجاح اختبارات القواعد لا يثبت وحده نجاح تجربة جهازين حقيقية.

- UNO يستخدم مجموعة 108 بطاقة وقواعد الحركة الأساسية، ويقبل محرك إنشاء الغرف الحالي من 2 إلى 10 لاعبين.
- الدومينوا يستخدم قطع الدبل ستة وحركات موضوعة على طرفي السلسلة.
- حيّة ودرج تستخدم رمية نرد وحركة قطع.
- الشطرنج له محرك قواعد محلي وخادمي.
- الطاولي الحالية **مبسّطة** ولا تُعلن على أنها تطبيق كامل لكل قواعد طاولة الزهر الرسمية.
- بعض مراحل تحدّي الأسئلة في محرك الغرف الحالي تحتاج استكمال التحكيم/التصحيح الآلي؛ لا تخلطها مع التدريب المحلي المستقل.

## التعليم والصوت

- يوجد شرح مصوّر وصوتي داخل بعض الألعاب، مع مساعد أوراس.
- الصوت المولّد من Gemini يتطلب اتصالاً؛ النصوص والإرشادات تبقى متاحة عند انقطاع الخدمة.
- اختيار الصوت في الحساب (افتراضي/رجالي/نسائي) تفضيل صوتي اختياري، ولا تُخزّن المنصة جنس المستخدم ولا تستنتجه من الاسم.
- التعليم الموحد الذي يحرك القطعة الحقيقية خطوة بخطوة لم يُعتمد بعد في جميع الألعاب. لا نعلن اكتماله حتى يُختبر في كل لعبة على حدة.

## المجتمع والتقدم

توجد وظائف للحسابات المجهولة، ملفات اللاعبين والصور والألقاب والإنجازات، البحث عن الأصدقاء، الرسائل العامة والخاصة، الحضور، والتقدم. يجب اختبار خصوصية كل مسار ومزامنته على حسابين فعليين قبل اعتبار النظام جاهزاً للإطلاق.

## التحقق وحدود الإصدار

- فحوص JavaScript وDeno واختبارات وحدات لبعض محركات الألعاب تعمل عبر GitHub Actions.
- اختبارات PostgreSQL المعزولة تستخدم بيانات وهمية ومعاملات تنتهي بـ`ROLLBACK`.
- هذه الاختبارات لا تستبدل اختبار هاتف فعلي، أو حسابين على جهازين، أو انقطاع الشبكة والعودة، أو اختبار وضع الطيران.
- لا تعتمد إصداراً عاماً قبل مراجعة الصلاحيات، واختبار كل لعبة منفردة، ثم الجهازين، ثم انقطاع الاتصال والاستعادة، ثم الأوفلاين، ثم الصوت والتعليم.
- لا تضع مفتاح `service_role` أو أي سر في ملفات الواجهة. مفاتيح Gemini وSupabase السرية تبقى داخل Edge Functions فقط.

## الوضع الحالي

هذا الفرع مرشح اختبار منفصل. أي تغييرات في هذا الفرع أو طلبات المراجعة لا تُعد منشورة على GitHub Pages ولا تُطبّق تلقائياً على قاعدة Supabase الإنتاجية. تبقى الألعاب أو الوظائف التي لم تجتز اختبار القبول معلّمة على أنها غير معتمدة للنشر.
