# سَـوَاد وناسة | Suwad Wanasa

منصة ألعاب اجتماعية عربية بطابع عراقي: **لَمّة، ضحك، وخَبْصة!**

## أقسام المشروع
- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.
- PWA قابلة للتثبيت، ونسخة مخزنة للواجهة والملفات الأساسية دون اتصال.
- ألعاب محلية على جهاز واحد: تخمين الشخصية، تخمين الرقم، برا السالفة، منو الأكثر، وممنوع إي ولا.
- ألعاب غرف أونلاين مبسّطة: حيّة ودرج، دومينوا، طاولي مبسّطة، كروت الألوان، تحدّي الأسئلة، والدولاب المشترك.
- حسابات بأسماء مستخدمين ومعرّفات صداقة، طلبات صداقة، رسائل خاصة، وشات عام محفوظ على Supabase.
- شروحات مصوّرة وصوتية للأطوار المتاحة.
- واجهة شخصيات ذكاء اصطناعي خيالية مع محادثة صوتية مباشرة عبر WebRTC (تحتاج إعداد المفتاح وترحيل الحصة ونشر Edge Function قبل التشغيل).

## إعداد الخلفية
يستخدم المشروع Supabase Auth وPostgres وRLS. للإعداد الجديد شغّل `supabase-schema.sql` كاملاً، وفعّل Anonymous Sign-Ins، واضبط Site URL، ثم ضع Project URL والمفتاح العام فقط في `backend-config.js`.

للمشاريع القديمة شغّل الترحيلات المطلوبة، وخصوصاً `supabase-public-chat-migration.sql` للشات العام و`supabase-wheel-migration.sql` للدولاب. راجع [SUPABASE-SETUP.md](SUPABASE-SETUP.md).

## حدود التنفيذ الحالية
بعض ألعاب الغرف نسخ مبسّطة. الدومينوا وضع مفتوح تظهر فيه القطع، والطاولي ليست تطبيقاً كاملاً لقواعد الطاولة، وبعض أطوار الأسئلة والتصويت تعتمد التحكيم والاتفاق بين اللاعبين بدلاً من احتساب آلي كامل. لا نصف هذه الأطوار بأنها مكتملة القواعد قبل استكمالها واختبارها.

## التحقق والنشر
كل push إلى `main` يشغّل GitHub Actions لفحص صياغة JavaScript، الروابط المحلية، ملفات PWA، تطابق مفاتيح الألعاب مع SQL، ووجود واجهة الشات العام وسياساتها. نجاح هذه الفحوصات لا يغني عن اختبار حسابين حقيقيين على جهازين.
يُنشر الموقع عبر GitHub Pages. لا تضع مفتاح `service_role` أو أي سر في ملفات الواجهة.

- محرك دومينو أونلاين v2 بأيدٍ خاصة وقواعد خادمية (يتطلب ترحيل قاعدة الاختبار ونشر Edge Function قبل التشغيل).
